= Working on the organisation profile

Clone https://github.com/stuff-of-awe/.github and edit profile/README.md or profile/assets/. No application build, service installation, package registry or container deployment is needed.

Install just and Nickel to run the inherited RSR metadata tooling. From the repository root run just validate-rsr, bash scripts/check-no-placeholders.sh ., and bash scripts/check-profile.sh. When the deed changes, run bash .machine_readable/arrival-pack/generate.sh and bash scripts/gen-repo-map.sh --worktree . to refresh derived documentation.

Review the diff and publish a signed commit. Verify the organisation page after publication. Avatar and social-preview settings require a separate GitHub settings update.
