= Cross-estate prover evidence: bounded source sample
:revdate: 2026-11-15

This is an *aspect-oriented source inspection*, not an executed CI/proof
report and not a complete enumeration of the estate. Search sampled four
external-prover names across selected default-branch files in the
`hyperpolymath`, `metadatastician`, and `catachresis-colloquium` organisations;
each GitHub search was capped at *20 hits*. Searches can omit repositories,
nondefault branches, generated artefacts and unindexed data. For exhaustive
sampling criteria see https://github.com/stuff-of-awe/.github/issues/18[issue #18].

The live `hyperpolymath/echidna`

== Assurance ladder for counting coverage

. *Declared*: a configuration, enum or named tool reference exists.
. *Implemented source*: an adapter/proof/gate function exists in the tree.
. *Execution witnessed*: pinned toolchain invocation with actual input,
  receipt and zero skipped obligations.
. *Certificate independently checked*: the produced witness was replayed
  under documented logic and checker.
. *Checker implementation verified*: an explicit mechanised checker-soundness
  theorem applies to the actual implementation, trusted base and format.
. *End-to-end verified executable*: a theorem connects the produced executable
  behaviour with the claimed property; a verified compiler alone is insufficient.

The presence of a curated awesome-list entry establishes only navigation
coverage. It cannot upgrade any item's assurance level. Prioritise
https://github.com/stuff-of-awe/.github/issues/17[PR governance incident]
and https://github.com/stuff-of-awe/.github/issues/16[canon release issue]
before closing correctness claims.
