# Contributing to Stuff of Awe

Suggest additions in the relevant awesome list. Include the canonical URL, a short factual description, the intended section, and why a reader would find it useful. Disclose if the project is yours. Prefer original sources, working links and useful distinctions over promotional claims. Keep upstream attribution when working in a fork; follow its own contribution rules.

For a new list, explain its scope and how it differs from existing collections. JTV and AffineScript collections are planned, not published by this profile update.

Keep pull requests focused and explain what changed. Credit sources and preserve existing licence notices. Check links and spelling, and provide meaningful image alternative text. Never include credentials or private information.

Repository-specific guidance takes precedence over this organisation fallback. For profile changes, run the checks in README.adoc. Respect contributors and discuss the work rather than the person.
