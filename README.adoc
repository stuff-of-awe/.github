= Stuff of Awe: organisation profile

Organisation profile, curated-list guidance and community defaults for awesome collections.

The public organisation page is rendered from link:profile/README.md[profile/README.md].
This repository is instantiated from https://github.com/hyperpolymath/rsr-template-repo[the RSR template]. It is not a game, library, or deployable service.

== Layout

* profile/README.md: public introduction.
* profile/assets/: hero, social image and avatar; CC also includes its one-shot animation.
* CONTRIBUTING.md and .github/: contribution guidance and shared GitHub defaults.
* github_chora.deed: identity, scope and template provenance. The filename omits the leading dot so estate deed discovery works; the canonical repository name remains .github.
* scripts/, build/ and .machine_readable/: inherited RSR governance tooling. Application scaffolding retained by that spine is not a claim that this profile ships an application.

== Maintain

Edit the profile and its assets, then run:

[source,shell]
----
just validate-rsr
bash scripts/check-no-placeholders.sh .
bash scripts/check-profile.sh
----

GitHub renders the profile from the default branch. Set the organisation avatar and repository social preview in GitHub settings; committing the files alone does not change those settings.
